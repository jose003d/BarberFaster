Coloca aquí las migraciones nuevas que deben ejecutarse automáticamente en producción.

Usa nombres `YYYYMMDDHHMMSS_descripcion.sql`, en minúsculas, y una sola sentencia SQL por archivo. No edites ni borres archivos que ya se aplicaron; crea una migración posterior para revertir o modificar el esquema.

Las migraciones históricas de `database/migrations/` no se ejecutan automáticamente.
